BHARATVIBES 🇮🇳 — FINAL LOCAL MVP
================================

આ build ખાસ કરીને Photo + Video posting માટે IndexedDB વાપરે છે જેથી મોટા media files localStorageની 5MB મર્યાદાથી અટકે નહીં.

મુખ્ય features:
- Photo + Video upload અને preview/playback
- Video controls + mute/unmute
- Upload/read progress
- Home Feed + Profile Posts
- Like 0→1→2 / Unlike decrement
- Comments, Save, Share/Copy link
- View count: screen પર 65%+ દેખાય ત્યારે એક user માટે એક view
- Profile photo/edit
- Public / Followers / Private
- Follow / Unfollow
- Notifications
- 1-to-1 Messages
- Search / Discover
- Report / Not interested
- Settings / Logout
- Responsive mobile + desktop UI
